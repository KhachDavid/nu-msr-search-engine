Navigation

  • The goal is to use the simulated robot to map an environment and then navigate within the map using the slam_toolbox

The Environment

  • Clone the package nubot, which is a package that simulates a mobile robot with a lidar in Gazebo.
  • Your repository will be next to nubot in the source space: e.g.(ws/src/nubot and ws/src/homework4).
  • I purposely did not put a README.md in nubot, so you will need to explore it to find out how it works.
  • HINT: There is one launchfile that runs the simulation and visualizes it in rviz.
  • HINT: There are two worlds to use, either will be accepted for the assignment but one is significantly smaller (and hence easier to explore).

Navigation Stack Setup

  • Going through the First-Time Robot Setup Guide (through setting up the robot's footprint) will help you understand how the Nav2 stack works, and may be a helpful reference while completing this assignment.
  • Much of the setup, however, is already done for you in nubot.
  • By running the launch file in the nubot package you will be able to see what features required by nav2 are already implemented.

A Launch File

  • Your package will be called nubot_nav
  • In nubot_nav, write a launch file called manual_explore.launch.xml that:
    • Starts the nubot simulation.
    • Starts the nav2 stack with SLAM enabled (to run slam_toolbox, create cost-maps, and enable navigation).
      • Use bringup_launch.py from nav2_bringup with slam:=True
      • Make sure to set a parameter to increase the footprint of the robot so that it encompasses the whole robot
        • Note: the footprint may appear multiple times in the configuration file
      • You may use a circular approximation of the robot
    • Starts rviz and displays:
      • The robot relative to the /map frame
      • The global costmap
      • The local costmap (with the costmap color scheme)
      • The planned path
  • Record a video of the robot mapping the environment until at least 1 corridor is mapped.
    • You can manually set waypoints using rviz2
  • HINT: You must enable simulation time when using the launchfiles to start navigation and SLAM

Customizing Nav2 Parameters

  • Use ros2 launch nav2_bringup bringup_launch.py --show-args to determine
    • The argument used to specify the nav2 parameters
    • The location of the default nav2 parameters file
  • Copy the default parameters into your own package under config, modify it as needed, and be sure to load it with your own launch configuration

Autonomous Exploration

  • Write a node called explore that causes the robot to explore the environment autonomously while mapping the world.
  • The launchfile called explore.launch.xml should start all the nodes necessary to allow the robot to explore and map its environment
    • This launchfile should include manual_explore.launch.xml and then start the explore node.
  • Use the map_saver_cli in the nav2_map_server package to save the resulting map and place it within the maps directory of the git repository
  • Record a video of the robot exploring the environment in rviz (you need not capture what the robot is doing in gazebo)

Exploration Algorithm

There are three choices for exploration algorithm:

  1. Frontier Exploration.
    • See Robot Frontier for a friendly description, in particular Detecting Frontiers
    • This is the most established method and most difficult to implement.
    • Students who successfully complete this method will receive extra credit
  2. Random exploration: some variation of the following algorithm:
    • Choose a random waypoint
    • Travel to the waypoint
    • Repeat
    • This method receives standard credit
  3. An algorithm of your choice:
    • The exploration does not need to be complete, perfect, or optimal, but it should be generic (so no hardcoding locations that work for this particular room).
    • The algorithm should be described or cited in the README.md
    • Extra credit may be received (at my sole discretion) based on whether it is qualitatively closer (in terms of effectiveness) to Frontier Exploration or Random Exploration.
