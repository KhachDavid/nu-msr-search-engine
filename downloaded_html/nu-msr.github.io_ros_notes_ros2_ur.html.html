Introduction

UR robots have a unified interface for controlling them.

The robots we have in the lab are UR7e robots.

Software Setup

  1. Install the ur ROS package for your current ROS distribution via apt
    • (e.g., on lyrical sudo apt install ros-lyrical-ur)
  2. Add a static ip connection nmcli con add type ethernet con-name UR ifname <ETH0> ip4 192.168.56.1/24
    • Replace <ETH0> with the name of your ethernet device (run nmcli to list them)

Mock Robot Controller

  • The fake robot controller: ros2 launch ur_robot_driver ur_control.launch.py ur_type:=ur7e robot_ip:=none use_mock_hardware:=true launch_rviz:=false
  • Moveit: ros2 launch ur_moveit_config ur_moveit.launch.py ur_type:=ur7e launch_rviz:=true
  • We let the moveit launchfile start rviz so that we get the full moveit rviz setup.

No Robot, No Problem

Run a MoveIt kinematic simulation of the robot locally, even when not connected.

  • ros2 launch franka_fer_moveit_config demo.launch.py

The Robot

  1. Power on the robot by pressing the button on the teach pendant
  2. In the lower left corner of the screen press the power button and unlock and activate the robot
  3. Press the Play button on the bottom middle of the screen
    • The program should be called ros_control
  4. In one terminal ros2 launch ur_robot_driver ur_control.launch.py ur_type:=ur7e robot_ip:=none use_mock_hardware:=true launch_rviz:=false
  5. In another terminal ros2 launch ur_moveit_config ur_moveit.launch.py ur_type:=ur7e launch_rviz:=true
