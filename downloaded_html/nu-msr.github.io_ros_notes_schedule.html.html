Building Documentation

  • As of 9/2026, the API documentation, hosted at https://docs.ros.org/en/lyrical/p/<package> are broken.
    • https://github.com/ros2/ros2_documentation/issues/7185
    • https://github.com/ros2/ros2/issues/1877
  • As a workaround, I recommend building the documentation locally using rosdoc2
    • Links in the notes may point to the rolling version until this bug is fixed, but the online API documentation is often incomplete.
    • The version of rosdoc2 that ships with ROS 2 is also broken, so these instructions contain a workaround for that as well.

  • Below is an example for rclpy. 

    mkdir -p ~/ws/ros_docs
cd ~/ws/ros_docs
git clone https://github.com/ros/rclpy -b lyrical
python3 -m rosdoc2.main build --package-path rclpy/rclpy
  • Documentation is available in ~/ws/ros_docs/docs_output/rclpy/index.html
  • Change the repository you clone to the source code of the package you wish to build documentation for
  • Change the --package-path argument to rosdoc2 to the directory containing the package.xml for the package you wish to document
